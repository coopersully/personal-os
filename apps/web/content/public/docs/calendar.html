calendar: see the time you actually have

calendar combines time across your connected calendars while keeping source, time zone, and editability visible. use it to plan a week, inspect overlapping commitments, or find space for focused work.

what you can do

  • browse events across selected calendars and choose which calendars are visible.
  • create and edit events in writable calendars, including supported timing and event details.
  • manage local calendars, inspect event details, and use deletion, trash, or restore when supported.
  • search events and navigate to dates. check the time zone and source before changing an event.
  • review calendar attention items and the evidence behind proposed changes.

what an agent can do

with the relevant grants, an agent can list calendars and events, inspect status and reviews, preview a commitment, and create or update supported events and time blocks. it can help compare proposed time with existing commitments before making a change.

provider capability still matters: a read-only calendar does not become writable through an agent. unsupported recurrence edits or invitation responses are not implied by basic event editing. ask the agent to check the source and available operations before changing a recurring meeting or replying to an invitation.

why it works this way

a unified view should make time easier to understand without rewriting provider truth. a hidden calendar is a display choice, not evidence that its events disappeared. previews and time-zone-aware reads help you catch conflicts before changing shared plans.

try this: “find a free hour for the final edit this week. show me the proposed slot and any conflicts before creating a block.” you can also select a writable calendar and create the event yourself.
