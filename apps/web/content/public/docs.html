Using nohmi

A practical guide to your workspaces, connections, and controls.

Start with your account

Open nohmi and sign in. If registration requires an invitation, use the invitation you received. Choose your local time zone and review your profile and settings before enabling connected services.

Connect only what you need

Use the setup and connection controls available in each workspace to connect supported mail, calendar, or financial providers. Read the requested permissions before authorizing access. A connected service may need you to sign in again when access expires.

A connection error or outdated record does not mean the external action succeeded. Check the status in nohmi and, when necessary, confirm the result with the original provider before repeating a consequential action.

Work directly

  • Use Mail for messages and mailbox actions.
  • Use Tasks for tasks, lists, projects, and reminders.
  • Use Calendar for events and scheduling.
  • Use Finances for accounts, transaction review, and budgeting.

Settings contains account preferences, connected agents, communication settings, and activity. Available actions depend on the permissions and capabilities of your connected services.

Delegate deliberately

Connect your chosen agent through nohmi’s agent connection flow. Grant only the access it needs. Inspect proposed actions and recorded results; an agent’s confident response is not proof that a provider accepted a change. Review data and agent access before granting access to sensitive material.

Enable optional texting

Open Settings → Texting, enter your mobile number, read the disclosures, select the consent checkbox, and verify the code sent to your phone. The same enrollment may be opened from your profile. Texting is optional and requires an available texting service. See SMS terms and enrollment.

Get help

For access, synchronization, texting, or privacy questions, visit Support. Include the affected feature and approximate time, but do not send passwords, verification codes, full financial account numbers, or private message contents.
