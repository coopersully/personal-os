mail: keep conversations moving

mail brings connected accounts into a combined inbox while preserving which account each conversation belongs to. it is useful when a project spans several inboxes or when you need to separate messages that require action from messages you only need to read.

what you can do

  • browse the combined inbox or individual accounts; use unread, starred, snoozed, sent, and drafts views.
  • search synced mail, read conversations, inspect attachments, and use the organization actions supported by the account.
  • compose a message, reply, or forward. drafts autosave so you can return to unfinished work.
  • review the recipient and exact draft before sending. inspect draft recovery when delivery is uncertain.
  • review obligations, questions, dispositions, and proposed rules in the mail review workflow. give feedback when an interpretation is wrong.

what an agent can do

with access, an agent can search and read mail, inspect threads and attachments, create and edit drafts, record obligations, and prepare response briefs. it can preview rules, inspect unresolved questions, and request a maintenance review. these tools help preserve the connection between a recommendation and the conversation that supports it.

sending through an agent requires the applicable write and explicit execution permissions and your configured authorization. ordinary maintenance does not silently send mail. a response brief is planning material, not a sent message. if a send result is uncertain, reconcile it with provider evidence before trying again.

why it works this way

reading, deciding, drafting, and sending are separate steps. that lets you delegate preparation without losing control over communication. keeping account identity and delivery state visible prevents a unified inbox from hiding where a message came from or whether it actually went out.

try this: “find the cinema conversation, tell me what still needs a reply, and draft a thank-you. leave it for me to review.” start by reading the conversation yourself, or review the agent’s draft in mail before sending.
