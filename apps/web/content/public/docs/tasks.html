tasks: turn intentions into commitments

tasks is where you capture what needs doing and organize it into a workable plan. a list holds an ongoing responsibility or context. a project holds a finite outcome. tasks and reminders let you keep the next action visible without treating every intention as a calendar appointment.

what you can do

  • capture tasks and reminders; edit their details and organize tasks into lists and projects.
  • use inbox, today, upcoming, later, open, and completed views to find the right slice of work.
  • set supported dates, priority, and planning details. distinguish a deadline from the time you intend to work.
  • move tasks or projects, complete or cancel work, and use archive, trash, or restore where available.
  • search and filter the workspace. import commitments from supported sources when you want to bring existing work into nohmi.

what an agent can do

an authorized agent can read lists, projects, tasks, and reminders; create or update them; move work; and change supported lifecycle states. it can help turn a large outcome into smaller actions, identify stale commitments, and suggest priorities using context you have provided. changes use the same records you manage manually.

give the agent explicit constraints: which project to use, what must remain unchanged, and whether it may update dates or complete items. a task being marked complete records a decision; it is not proof that an external real-world action happened.

why it works this way

tasks owns what you intend to do. calendar owns when time is reserved. keeping them distinct lets you plan without filling every open hour or confusing a due date with a meeting. imports bring work into nohmi; they are not a promise of continuous two-way synchronization with every original task provider.

try this: “break the premiere into venue, invitations, and final delivery tasks. put them in one project. suggest dates, but leave existing deadlines alone.” you can make the same project and tasks manually, then ask for a second pass.
