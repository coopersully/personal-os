# Desktop downloads and updates

The immediate job is to install the right Mac app or understand whether the
installed app needs an update. This is a Settings utility and a standalone public
`/downloads` page, not a workspace.

Use one primary release Card: version and minimum macOS version, an ItemGroup for
Apple Silicon/Intel installers, installation instructions, then collapsed release
notes and the source release. Do not show a download until its immutable artifact
has been validated. In the installed app, the adjacent update Card owns current
version, truthful lifecycle status, progress and manual check/restart.

Loading, unpublished, unavailable and self-hosted configuration are distinct.
Retries remain local to the failed read. Keyboard actions use native buttons and
links; status changes use live status text. Installation confirmation uses the
shared Dialog and cannot be dismissed while replacement is underway. No new
colors, motion, icon packs or primitive overrides are introduced.

The startup Card replaces the interactive app until update checking completes,
fails or the person selects Open now. Opening permanently revokes automatic
installation for this process. Do not mount forms behind this screen. Download
progress is determinate only with a known byte total. Installing disables escape.
