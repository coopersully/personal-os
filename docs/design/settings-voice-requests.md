# Settings Voice Requests

Running list for the current voice iteration. Durable rules also live in the
Settings UI standards and frontend skill.

- [x] Single-line settings use the same compact 48px row. Remove nested wrapper
  padding and keep divider paint from adding height. Descriptions grow naturally.
- [x] Leading icons reserve the same invisible 32px frame footprint whether or
  not they have a visible tile. Center unframed provider artwork at the same glyph
  position and size as framed settings icons; do not add a visible Google frame.
- [x] Security uses compact Password and Session rows. Password opens a focused
  reset-link dialog; Session opens a logout dialog. Keep action feedback in Sonner.
- [x] Subpage headers use the parent icon, with a smaller subpage badge at bottom-right.
- [x] Right-click a Settings sidebar page to select its available subpages.
- [x] Goals and Motives show saved-record counts in the sidebar.
